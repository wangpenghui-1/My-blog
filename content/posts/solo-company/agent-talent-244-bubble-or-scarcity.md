**数据时效：2026-08**
智联招聘 2026 上半年报告里有两个数字。AI 智能体开发岗位的需求同比涨了 244%。人工智能工程师的需供比是 2.62 比 1。央视财经把这两个数放在同一篇报道里，读起来很顺，市场特别缺会搭智能体的人。

这个读法站不住。244% 是增速，不是总量。出现这么高的同比，先要看基数。智能体开发作为一个明确的岗位方向，去年还很小众。基数小，稍微涨一点，同比就冲得很高。AI 产品经理职位的增速也有 87.7%，数据标注和 AI 训练师是 30.3%，都不算小。要判断一个方向真缺不缺人，光看增速会把人带偏。2.62 比 1 是另一个口径。它算的是整个人工智能工程师群体，每名求职者摊到约 2.6 个岗位。这个比例常被读成缺口，但它同时说明，供给正在快速跟上来。两个数字量的是两件事，拼成一个缺口故事，读着过瘾，经不起压。

汽车研发和制造行业的人工智能工程师，需供比是 8.2，比全国平均高一截。同一头衔，换到不同行业，供需天差地别。所以缺不缺人，跟着行业和层走，不跟着一个统一数字走。

那缺口到底在哪。我翻了报告里对智能体岗位的拆解，又看了几家做 Agent 的公司怎么定义岗位，得到一个判断。市场真正缺的，是能定义行为边界、搭起运行时、端到端把 Agent 运维下来的人。会调 API 只是入场券。

## 从拼模型，到拼运行时

2026 年这场竞争，焦点从模型本身挪到了模型之外那层壳。业内用一个式子描述它，模型加 Harness 等于 Agent。Harness 不好翻译，理解成驾驭大模型运行的那层壳就接近了。模型是引擎，上下文窗口是内存，Agent 是要跑的程序，Harness 是操作系统。它负责工具怎么被调用，上下文怎么组织，权限谁能碰，任务状态怎么被记住。

DeepSeek 在 8 月 13 日把 Harness 的开发者预览版开源了，版本 v0.1，仓库在 GitHub 上。它的核心叫 Cordis，是个微内核，只做三件事，插件的装载、卸载、依赖关系管理，不碰任何具体能力。模型、工具、技能、会话、沙箱、存储、循环调度、界面，全做成插件，想换就在配置层换，不用动源码。它自己做的东西不多，但把 Agent 能力怎么组装这件事，变成了一个可以量产的工程。

千问办公走的是同一条路，方向反过来，从产品侧往运行时侧做。8 月 26 日它上线 Qwen3.8-Flash，配合所谓标准模式。官方给出两个数，单任务生成速度提升约 100%，Token（模型处理的语言单位）消耗平均减少 75%。日常任务大概九成五用标准模式就能跑完，只有约一成的复杂任务才动用高级模式。第一财经的稿子直接说，千问办公靠推理优化和定制 Harness 架构把吞吐提上去。一家面向企业办公的产品，把 Harness 写进自己的性能叙事，说明这层已经落进工程里。

## 缺口在哪一层

Agent 架构师，管整体设计，选模型和工具链，定义行为边界和安全策略。需求量小，整份报告里大概占百分之二点七，但最难找，要同时懂大模型和系统工程。这一层的护城河最深，行为边界这种东西，模型能力再强，也得有人来画。

技能工程师，把业务流程封装成 Agent 能调用的技能，做 API 调用、提示词、函数调用。这层看着光鲜，护城河最浅。提示词和函数调用正被模型自身吸收，过几年大概会变成普通开发者的常识，很难做成长期壁垒。

Agent 运维，也叫 Agentic DevOps，是另一回事。它管长流程的状态，任务跑到一半断了怎么恢复，工具调用可不可靠，权限和审计怎么留痕。这一层的缺口，长在具体的招聘启事里。中国移动旗下有家公司招智能研发平台架构专家，十多年 DevOps 经验起，岗位描述写的是让 Agent 在研发全流程落地，把智能需求拆解、编码辅助、自动化测试、缺陷定位、智能发布运维串起来。这种活是脏活，恰恰最值钱。

Agent 产品经理，需求量最大，增速也最快。它对能力边界要有判断，能设计可落地的方案，定义效果指标，为一个业务结果负责。护城河取决于懂不懂行业，不完全在技术。

## 落没落在真实任务上

判断一种能力是不是真稀缺，要看它落在真实任务上，而不是看演示。

千问办公由阿里三款产品合并，8 月 3 日公测。它的定位是打通本地电脑操作、云端工作流和企业协同，变成一个入口。你用自然语言提出需求，授权以后它替你去浏览网站、操作本机文件、把复杂多步任务编排完。定时任务它能做，设一个每周一早九点汇总上周销售数据、生成报告发群组，它会自动触发，拉数据，生成 Excel 加 PPT，发进钉钉群，全程不等你。碰到完整竞品分析这类大任务，它自动拆成几条子任务并行跑，完成速度跟任务数量脱钩。第三方实测过，七分钟做完十二页财报 PPT，两分钟听完一段播客并总结。但也有毛病，跨应用转文档会乱码，网页生成任务能跑上一个小时。



美团 CatPaw 走本地生活，7 月 27 日上线。官方说内部九万人用过，建了三万个 Agent，餐饮、美业、宠物医院都在跑。它的特点是懂生意。新店选址，能想到上楼动线、排烟、消防、前店主为什么关店、合同会不会涨租。经营诊断，能把 GMV（成交额）下滑拆成流量、转化、客单价、复购、评价、履约、营销 ROI 七个维度。

但第三方实测给了一个诚实的数字，整体完成度约五成。它听得懂诉求，搞不好落地，财务测算尤其弱。平台自己把限制说得很清楚，改价格、发活动这类关键决策，仍然由人做，AI 负责信息整理、问题呈现和策略建议。

所以怎么判断一个 Agent 是真的，还是编排好的演示。我的标准是三条。任务跑到一半，工具或上下文变了，它能不能自己重新规划。隔一阵再进来看，它记不记得上次做到哪。碰到不可逆的动作，比如付款、删数据、改对外策略，它会不会停下来先要一个授权确认。三条都过关，才算得上真。编排演示通常只走一条写死的流水线，遇到边界情况就安静地出错，也没有权限这回事，因为背后其实是一个人替它做编排。

## 这串数字没告诉你的

企业真正想要的，是懂 AI 又懂行业的人。深圳神铼科技的董事长说，人工智能和行业结合应用这类复合型人才的需求基本翻番。当自动化、应用数学、机械工程这些学科的人涌进来，纯算法能力的定价在往下走，懂行业、能把 Agent 扛进生产环境的人往上走。下半年薪资也能看到一个偏，智联招聘华南区总经理杨娟说，贴着实体产业、落地属性强的岗位，涨幅普遍在百分之十几到三十。深圳梨云文化科技的人力资源总监熊辉说，下半年 AI 人才薪资涨幅可能到百分之三十到四十，还会放宽专业限制。

端侧也在走。DeepSeek Harness 的迭代版本加了原生图片请求、图文混合输入，有人把它接到带算力的边缘设备上，断网也能对话、检索、执行。全模态实时交互加端侧轻量推理，是这条路上未来半年更值钱的研发方向。这是推测，会不会真兑现，看它能不能在真实业务里扛住稳定性。

一个人如果想往这行走，功夫要下在底层。任务怎么拆，工具怎么调度，这两样练熟，框架换几茬都接得住。再往深处，把评测当成一件天天要做的事。Agent 工业化最后会不会变成一门被认证的工种，还是只变成一个贴在岗位上的新标签，得看企业是不是真按这四层去招、去考核、去给钱，而不是只贴一个 Agent 头衔。
