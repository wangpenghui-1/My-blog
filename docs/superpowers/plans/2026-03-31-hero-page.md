# Video Hero Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the existing homepage cover with a full-screen video hero section followed by a paginated article list.

**Architecture:** The Hugo theme already hides its header on homepage (`body.is-home .header { display: none }`). We override `body.is-home .main` to remove container width/padding constraints, replace `layouts/index.html` with the new hero template, and append all hero CSS to `assets/css/extended/digital-garden.css`.

**Tech Stack:** Hugo Go templates, vanilla CSS, Google Fonts (Barlow + Instrument Serif)
